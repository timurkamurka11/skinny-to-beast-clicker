# Production Fat Man — Animation Clip Matrix 3.7

Документ задаёт минимальный набор клипов, тайминг, loop-настройки, события и требования к движению.

## Общие правила

- project sampling rate: 30 fps;
- допускается 60 fps только для коротких facial clips, если это доказанно улучшает результат;
- Root Motion выключен;
- первый и последний кадр loop-клипа совпадают по transforms и Sprite Resolver states;
- все clip names начинаются с `FM_`;
- все события звука вызываются через Animation Event только там, где звук должен совпасть с конкретным контактом;
- gameplay-код остаётся главным источником логики, Animator не начисляет валюту и не меняет stage;
- secondary motion не должна накапливать ошибку после прерывания клипа.

## Параметры Animator

| Parameter | Type | Назначение |
|---|---|---|
| Facing | int | 0 Front, 1 SideLeft, 2 SideRight, 3 Back |
| Stage | int | 0–3 |
| Speed | float | 0 idle, 1 normal walk |
| Tap | bool | true во время короткой tap-reaction |
| Action | int | CharacterRoutineAction |

## Base Locomotion

### FM_Idle_Breathe

- длительность: 4.0 сек;
- loop: да;
- ракурсы: Front/Side/Back;
- движение таза: вертикально 0.4–0.8% высоты персонажа;
- грудь: плавный вдох 55% цикла, выдох 45%;
- живот: запаздывание 2–3 кадра;
- голова: стабилизация с микродвижением не более 0.5°;
- руки: едва заметная инерция;
- лицо: нейтральное, blink управляется отдельным layer.

### FM_Walk

- длительность: 0.80 сек на полный двухшаговый цикл;
- loop: да;
- ракурсы: Side обязательно, Front/Back отдельные циклы;
- контакты стоп: кадры 0 и 12 при 30 fps;
- passing poses: кадры 6 и 18;
- таз: вертикальное движение до 2.2% роста;
- руки и ноги в противофазе;
- дальняя конечность имеет меньшую амплитуду во Front/Back;
- живот запаздывает на 2–4 кадра;
- стопа не скользит в контактной фазе;
- события: `FootstepL`, `FootstepR`.

### FM_SitDown

- длительность: 0.90 сек;
- loop: нет;
- центр массы сначала уходит назад, затем вниз;
- живот слегка сжимается, но не инвертируется;
- руки помогают балансировать;
- финальный кадр точно совпадает с первым кадром `FM_SitLoop`.

### FM_SitLoop

- длительность: 3.2 сек;
- loop: да;
- дыхание сохранено;
- микродвижение ног и рук;
- blink и взгляд работают независимо.

### FM_StandUp

- длительность: 0.90 сек;
- loop: нет;
- начало совпадает с SitLoop;
- движение начинается с наклона корпуса вперёд;
- таз поднимается без резкого скачка;
- конец совпадает с Idle bind-compatible pose.

## Tap reactions

### FM_TapReact_01 — Surprise

- длительность: 0.34 сек;
- приоритет: высокий;
- плечи и голова быстро реагируют в первые 3 кадра;
- живот отстаёт на 2 кадра;
- рот `OpenSmall`;
- глаза могут кратко расшириться;
- возврат без snap.

### FM_TapReact_02 — HeavyBounce

- длительность: 0.42 сек;
- корпус сжимается вниз на 2–3%;
- живот и майка дают один контролируемый bounce;
- подбородок имеет минимальное запаздывание;
- запрещено больше одного полного колебания.

### FM_TapReact_03 — Annoyed

- длительность: 0.46 сек;
- голова слегка поворачивается;
- одна бровь поднимается;
- рот `Strain`;
- плечо делает короткий dismissive motion.

### Очередь тапов

- новый tap может прервать recovery после 60% клипа;
- не допускается одновременно больше одного Tap clip;
- амплитуда не увеличивается от числа нажатий;
- вариант выбирается gameplay-кодом либо StateMachineBehaviour, но без повторения одного варианта более двух раз подряд.

## Idle actions

### FM_ShiftWeight_L / FM_ShiftWeight_R

- длительность: 2.6 сек;
- перенос таза 2–4%;
- опорная нога почти прямая, свободная расслаблена;
- плечи компенсируют перенос;
- живот сохраняет объём.

### FM_LookAround

- длительность: 2.4 сек;
- сначала движутся глаза, затем голова;
- угол головы не более ±10°;
- грудь поворачивается на 2–4°;
- в конце взгляд возвращается в neutral.

### FM_Scratch

- длительность: 2.2 сек;
- используется `HandPose.Scratch`;
- локоть движется по читаемой дуге;
- 2–3 коротких движения кисти;
- после действия кисть возвращается в `Relaxed` до blend-out.

### FM_Yawn

- длительность: 3.6 сек;
- рот: Neutral → OpenSmall → Yawn → Exhale → Neutral;
- глаза: Half/Closed в центральной фазе;
- челюсть и подбородок связаны;
- плечи слегка поднимаются на вдохе;
- событие звука опционально: `YawnStart`.

### FM_Stretch

- длительность: 3.0 сек;
- руки поднимаются через естественную дугу;
- плечи не отделяются от торса;
- живот вытягивается не более 6%;
- рот `Strain`;
- в верхней точке удержание 0.35–0.55 сек.

### FM_Flex

- длительность: 2.3 сек;
- кисти `Fist`;
- грудь подаётся вперёд;
- локти не пересекают лицо;
- Stage 1 выглядит слегка неловко, Stage 4 увереннее;
- лицо `Strain`, затем короткий `Smile`.

### FM_AdjustClothes

- длительность: 1.9 сек;
- одна или обе руки тянут низ майки;
- ShirtHem двигается отдельно;
- ткань возвращается с одним небольшим overshoot;
- ладонь не проходит сквозь живот.

### FM_WarmShoulders

- длительность: 2.5 сек;
- круговое движение плеч небольшой амплитуды;
- голова стабилизирована;
- грудь и майка реагируют вторично;
- локти остаются в безопасном силуэте.

## Face clips

### FM_Blink_Single

- длительность: 0.13 сек;
- sequence: Open 2f → Half 1f → Closed 1f → Half 1f → Open;
- pupils скрываются при Closed;
- loop: нет.

### FM_Blink_Double

- длительность: 0.28 сек;
- два blink с промежутком 2–3 кадра;
- используется редко.

### FM_Face_MicroLook

- длительность: 1.2–2.0 сек;
- смещение зрачков не более 15% ширины глаза;
- не повторяется постоянно;
- отключается в Back view.

## Turn clips

### FM_Turn_Front_To_Side

- длительность: 0.22 сек;
- на 50% выполняется view swap;
- Root визуально сжимается по X максимум до 0.92;
- голова не прыгает по высоте;
- sorting конечностей меняется одновременно со swap.

### FM_Turn_Side_To_Back

- длительность: 0.26 сек;
- аналогичная схема;
- допускается промежуточный 3/4 sprite;
- в Back view facial renderers выключены.

### Обратные turn clips

- не использовать механический reverse, если clothing overlap выглядит неверно;
- при необходимости создать отдельные clips.

## Stage change

### FM_StageChange

- длительность: 0.9–1.3 сек;
- персонаж принимает устойчивую позу;
- Sprite Library Stage меняется в скрытой фазе light/scale pulse;
- scale pulse максимум 1.04;
- лицо: Surprise → Smile;
- gameplay event отвечает за FX и звук, Animator только визуализирует.

## Blend settings

- Idle ↔ Walk: 0.12–0.20 сек;
- Idle ↔ Action: 0.08–0.15 сек;
- Action → Idle: 0.12–0.22 сек;
- Tap: вход 0.03–0.06 сек, выход 0.08–0.14 сек;
- Sit transitions: 0.05–0.10 сек;
- Turn: минимальный crossfade, чтобы view swap не смешивал несовместимые sprites слишком долго.

## Acceptance

Каждый clip принимается только после проверки:

- Front/Side/Back;
- Stage 1;
- нормальная скорость и 0.5× slow motion;
- отсутствие щелей и инверсии mesh;
- отсутствие foot sliding;
- чистый переход в Idle;
- отсутствие накопления secondary motion;
- тест 100 быстрых тапов;
- Android Play Mode/Development Build.
